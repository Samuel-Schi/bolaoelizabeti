Como usar:
1. Abra o arquivo index.html no navegador.
2. Clique em Atualizar API para puxar jogos/chaves.
3. Cadastre os participantes.
4. Lance os palpites em cada jogo.
5. Quando a API tiver resultado final, clique em Recalcular pontos.

Observação:
- Participantes e palpites ficam salvos no navegador via localStorage.
- Para usar com login real e várias pessoas ao mesmo tempo, o próximo passo é conectar com Supabase/Firebase ou criar backend.

API usada:
https://worldcup26.ir/get/games
https://worldcup26.ir/get/groups
https://worldcup26.ir/get/teams
